# Data Dictionary

## `data/historical_sales.csv`

This repository includes a **synthetic demonstration dataset** because no company dataset was supplied with the task prompt. It is generated deterministically by the project code and is intended to demonstrate the complete forecasting workflow.

| Column | Type | Description |
|---|---|---|
| `Date` | date | Business transaction date |
| `Product_Category` | categorical | Product category |
| `Region` | categorical | Sales region |
| `Units_Sold` | integer | Units sold on the date/category/region combination |
| `Unit_Price` | numeric | Average unit price used for the transaction group |
| `Discount` | numeric | Discount rate between 0 and 0.25 |
| `Marketing_Spend` | numeric | Simulated daily marketing spend |
| `Sales` | numeric | Revenue generated by the transaction group |

### Replacing the sample data

For a real business submission, replace `data/historical_sales.csv` with the supplied company dataset. The minimum required columns are:

- `Date`
- `Sales`

The pipeline can then aggregate records by date and rebuild the time-based features automatically.
